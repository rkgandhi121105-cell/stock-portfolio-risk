# Stock Portfolio Risk Analysis and Stress Testing Using Python

This starter implementation follows the uploaded project proposal. It downloads historical Yahoo Finance data for 4–5 NSE-listed stocks and the Nifty 50 benchmark, calculates portfolio risk metrics, applies simplified stress scenarios, compares the entered allocation with equal weighting, and displays charts and downloadable reports.

## Requirements
- Python 3.10 or newer recommended
- Internet connection for Yahoo Finance data

## Run on macOS
Open Terminal and move into this folder:

```bash
cd stock_portfolio_risk_project
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Streamlit will show a local URL, usually `http://localhost:8501`.

## Ticker examples
- `HDFCBANK.NS`
- `TCS.NS`
- `ITC.NS`
- `RELIANCE.NS`

You can enter a fifth ticker if desired. Yahoo Finance ticker availability and historical data can change.

## Measures included
- Daily percentage returns and hypothetical portfolio weights
- Annualised volatility using standard deviation × √252
- Maximum drawdown
- Beta relative to Nifty 50
- HHI concentration
- Return-correlation matrix
- Diversification Ratio
- Illustrative Low / Moderate / High rule-based label
- Stress tests: all holdings −10%, all holdings −20%, largest holding −30%
- User-entered allocation vs equal-weight allocation

## Important assumptions and limitations
- Amounts are hypothetical; no brokerage account is connected.
- Yahoo Finance data is retrieved at run time and may be unavailable or revised.
- The code uses `auto_adjust=True`, so the downloaded `Close` series is adjusted for corporate actions.
- For simplicity, portfolio historical returns are calculated as a daily weighted sum using the entered starting weights. This is a constant-weight approximation; it does not rebalance holdings each day.
- Stress tests apply shocks to the current hypothetical portfolio amount, not to historical holdings through time.
- The risk thresholds are educational project rules, not universal industry standards.
- This tool does not predict stock prices or recommend buying/selling any stock.

## Suggested testing
1. Run the default sample portfolio.
2. Enter an invalid ticker and confirm a clear error is displayed.
3. Enter zero for every investment and confirm validation prevents analysis.
4. Try a shorter date range and confirm the minimum-observation check works.
5. Compare a concentrated allocation with equal weighting.


## New interface features
- Use **Add stock** / **Remove last** in the sidebar to manage 4–5 holdings, with a separate ticker and amount for each.
- The investment projection simulator lets you test a starting amount and a 1, 2, 3, 5, or 10-year horizon.
- Projection values are generated by resampling historical portfolio returns (a bootstrap simulation), with 10th percentile, median, and 90th percentile outcomes. This is not an AI prediction, a guarantee, or a recommendation.


## Data-download troubleshooting update
The app now downloads each ticker separately and reports which ticker has missing/unavailable data. This avoids some Yahoo Finance multi-ticker download/column-layout issues. If a ticker fails, verify that it is the exact Yahoo Finance symbol and that it has data for the chosen date range.
